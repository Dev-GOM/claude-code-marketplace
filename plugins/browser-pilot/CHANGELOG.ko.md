# 변경 이력

Browser Pilot의 모든 주요 변경사항이 이 파일에 문서화됩니다.

형식은 [Keep a Changelog](https://keepachangelog.com/en/1.0.0/)를 기반으로 하며,
이 프로젝트는 [Semantic Versioning](https://semver.org/spec/v2.0.0.html)을 준수합니다.

## [1.4.0] - 2025-01-06

### 추가됨
- 모든 문서에서 Smart Mode가 Direct Mode보다 우선적으로 권장됨
- 단일 및 체인 명령어에 대한 따옴표 규칙 명시적으로 문서화
- 모듈형 파일 구조를 가진 새로운 데몬 모드 핸들러 아키텍처
- 상세한 도움말 텍스트와 예제를 포함한 향상된 query 명령어

### 변경됨
- **주요 변경**: SKILL.md를 914 단어로 간소화 (1,504 단어에서 축소)
- 중복 방지를 위해 상세 문서를 `references/` 폴더로 이동
- 명확한 예제와 따옴표 규칙으로 체인 명령어 설명 개선
- 전체 18개 CLI 명령어 파일 (52개 이상 명령어)에 상세 설명 추가
- 모든 문서에서 Smart Mode 섹션이 먼저 나타나도록 재정렬
- 따옴표 규칙 명확화: 값에 공백이 포함된 경우에만 따옴표 필요

### 개선됨
- CLI 도움말 시스템 접근성
- Direct Mode보다 Smart Mode를 우선시하는 명령어 참조 문서
- 포괄적인 모범 사례를 포함한 셀렉터 가이드
- 명확한 쿼리 예제를 포함한 Interaction Map 문서

### 수정됨
- 체인 모드 예제에서 따옴표 규칙 명확화 (불필요한 따옴표 제거)
- 공개 문서에서 개인 프로젝트 예제 제거
- 각 괄호를 사용하여 플레이스홀더 형식 표준화 (예: `<url>`, `<login-url>`)
- 단일 모드 따옴표 규칙을 체인 모드와 일관되게 문서화

### 문서화
- Smart Mode에 "Recommended" 라벨과 시각적 강조 추가
- Smart Mode 장점을 보여주는 비교 표 업데이트
- Smart Mode 예제를 포함한 문제 해결 섹션 강화
- 문서 중복 감소를 위한 Progressive Disclosure 원칙 적용
